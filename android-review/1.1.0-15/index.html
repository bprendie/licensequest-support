Android background mileage demonstration

Decker’s LicenseQuest 1.1.0 (15). Actual Android emulator UI, stationary. No travel or mileage is simulated. This recording uses debug build 15. Build 16 replaces city lookup with an offline database; the demonstrated background-mileage service, notification, and Pause controls are unchanged.

The user creates a trip, explicitly enables background mileage, starts GPS, and allows notifications. While the app is backgrounded, the ongoing notification offers Pause mileage. That action stops the location service. The user returns and finishes the trip.

Sampling cannot be deferred without losing traveled segments. Coordinates are processed locally for distance; no route trail is retained. This stationary demonstration verifies controls and service lifecycle, not road accuracy.
